## The MLJ.jl Ecosystem

MLJ.jl provides a unified interface for machine learning in Julia with over 200 registered models. The workflow follows a consistent pattern: load the model type, instantiate with hyperparameters, wrap in a machine (binding model to data), fit, and predict.

using MLJ
Tree = @load RandomForestRegressor pkg=DecisionTree
model = Tree(n_trees=500, max_depth=10, min_samples_leaf=5)
mach = machine(model, X, y)
fit!(mach, rows=train_idx)
ŷ = predict(mach, rows=test_idx)

Scientific types (Continuous, Count, Multiclass, OrderedFactor) enable automatic preprocessing. Pipelines compose preprocessing and modeling steps: pipe = Standardizer() |> model. Hyperparameter tuning uses TunedModel with Grid, RandomSearch, or LatinHypercube strategies.

## Healthcare Feature Engineering

Claims-based ML requires extensive feature engineering. From raw claims, construct: comorbidity indicators (31 Elixhauser flags), prior utilization counts (ED visits, hospitalizations, specialist visits in lookback period), medication counts and therapeutic classes, cost summaries (total, inpatient, outpatient, pharmacy), demographic features, and temporal features (months enrolled, season of index event). One-hot encoding of categorical variables via OneHotEncoder() in MLJ pipelines.

Critical: temporal train/test splits prevent future data leakage. Use data from years 1-3 for training, year 4 for testing — never random splits that would allow future claims to predict past outcomes.

## Regularized Regression

LASSO for variable selection in high-dimensional claims data:

Lasso = @load LassoRegressor pkg=MLJLinearModels
model = Lasso(lambda=0.1)
r = range(model, :lambda, lower=1e-4, upper=10.0, scale=:log)
tuned = TunedModel(model, tuning=Grid(resolution=50), range=r, measure=rmse)

## Tree-Based Methods

Random forests and gradient boosting via EvoTrees.jl:

using EvoTrees
config = EvoTreeRegressor(nrounds=500, eta=0.05, max_depth=6, lambda=1.0, subsample=0.8)
model = fit_evotree(config; x_train, y_train, x_eval, y_eval)
predictions = predict(model, x_test)

Feature importance via permutation importance: for each feature, shuffle its values, re-predict, measure the increase in prediction error. SHAP values for model interpretation via ShapML.jl: for each observation, decompose the prediction into contributions from each feature, enabling clinician-interpretable explanations of risk scores.

## Causal Forests

Custom honest causal forest implementation: split the sample into tree-building and estimation subsamples. For each tree: bootstrap the tree-building subsample, grow a tree by recursively splitting on the covariate that maximizes the estimated treatment effect variance across child nodes. Apply the tree structure to the estimation subsample and compute within-leaf treatment effects as the difference in mean outcomes between treated and control observations. Average across B trees for the final CATE estimate. Confidence intervals via the infinitesimal jackknife (Athey and Wager, 2019).

Application: estimating which patients benefit most from a care management intervention, enabling targeted enrollment that maximizes health improvement per dollar spent.

## Double/Debiased Machine Learning

DML implementation with K=5 fold cross-fitting:

function dml_estimate(Y, D, X; K=5, ml_model=RandomForestRegressor())
    n = length(Y)
    folds = kfolds(n, K)
    residuals_Y = similar(Y)
    residuals_D = similar(D)
    for k in 1:K
        train_idx = setdiff(1:n, folds[k])
        test_idx = folds[k]
        # Estimate E[Y|X] on training fold
        mach_y = machine(ml_model, X[train_idx,:], Y[train_idx])
        fit!(mach_y)
        residuals_Y[test_idx] = Y[test_idx] - predict(mach_y, X[test_idx,:])
        # Estimate E[D|X] on training fold
        mach_d = machine(ml_model, X[train_idx,:], D[train_idx])
        fit!(mach_d)
        residuals_D[test_idx] = D[test_idx] - predict(mach_d, X[test_idx,:])
    end
    # OLS of residualized Y on residualized D
    θ_hat = dot(residuals_D, residuals_Y) / dot(residuals_D, residuals_D)
    se = std(residuals_Y - θ_hat * residuals_D) / (sqrt(n) * std(residuals_D))
    return (estimate=θ_hat, se=se, ci=(θ_hat - 1.96*se, θ_hat + 1.96*se))
end

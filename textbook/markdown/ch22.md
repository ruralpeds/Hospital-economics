# Chapter 22: Bayesian Computation in Julia with Turing.jl

## Introduction

Turing.jl is Julia's premier probabilistic programming framework, providing an expressive @model macro for specifying Bayesian models, automatic differentiation for efficient gradient-based sampling, and integration with Julia's optimization and distribution ecosystems. This chapter implements every Bayesian method from Chapter 15 in Turing.jl, providing production-ready code for Bayesian regression, hierarchical models, cost-effectiveness analysis, network meta-analysis, and spatial models.

## Turing.jl Architecture

The @model macro defines a probabilistic model using the ~ operator for distributional assumptions:

@model function bayesian_regression(X, y)
    β ~ MvNormal(zeros(size(X,2)), 10.0 * I)
    σ ~ truncated(Normal(0, 5), 0, Inf)
    μ = X * β
    y ~ MvNormal(μ, σ^2 * I)
end

Sampling uses the NUTS algorithm by default: chain = sample(bayesian_regression(X, y), NUTS(), 2000). Multiple chains for convergence assessment: chains = sample(model, NUTS(), MCMCThreads(), 2000, 4).

## Bayesian Hierarchical Models

Hospital quality profiling with shrinkage estimation:

@model function hospital_model(y, X, hospital_id, n_hospitals)
    β ~ MvNormal(zeros(size(X,2)), 10.0 * I)
    τ ~ truncated(Normal(0, 1), 0, Inf)
    α = Vector{Float64}(undef, n_hospitals)
    for j in 1:n_hospitals
        α[j] ~ Normal(0, τ)
    end
    for i in eachindex(y)
        p = logistic(dot(X[i,:], β) + α[hospital_id[i]])
        y[i] ~ Bernoulli(p)
    end
end

## Bayesian CEA

Joint modeling of costs and effects with CEAC construction from posterior draws. For each posterior draw k: compute ΔC⁽ᵏ⁾ and ΔE⁽ᵏ⁾, then NB⁽ᵏ⁾(λ) = λΔE⁽ᵏ⁾ - ΔC⁽ᵏ⁾. The CEAC at threshold λ is the proportion of draws with NB > 0.

## Bayesian NMA

Network meta-analysis with random effects for between-study heterogeneity, consistency checking, and SUCRA ranking from posterior treatment effect draws.
